The accompanying statistical tables report 95% confidence intervals, paired Dice differences, and Holm-adjusted p values. Confidence intervals were calculated using 2,000 image-level bootstrap resamples. Differences between methods were evaluated using two-sided paired sign-flip permutation tests with 4,999 random assignments and an add-one correction. Pairing and the four lesion classes were retained within each image. Figure 7 uses the corresponding intervals, and Figure 9 provides vertical confidence intervals for Dice. Figure 8 is linked to the saved evaluation outputs; the cross-dataset numerical comparisons are reported with Table 4. For Figure 4, Dice is calculated separately for each reference-positive lesion class and averaged equally over eligible classes within each image. Reference-empty classes receive undefined overlap scores, while false-positive counts are recorded separately. Images with no reference-positive class are excluded from the Dice distribution. These rules are implemented consistently in metric calculation, aggregation, bootstrap estimation, paired comparisons, and plotting, and are covered by boundary-case and end-to-end checks. The statistical procedure and record locations are documented in the accompanying code and README.
